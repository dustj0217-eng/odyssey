# 21세기 오디세이 — UI 개조본

## 적용 방법

1. 기존 프로젝트를 백업합니다.
2. `globals.css`는 기존 파일이 있던 위치에 덮어씁니다.
3. `Diary.tsx`, `GameShell.tsx`, `MythOverlay.tsx`, `Planner.tsx`, `StartScreen.tsx`, `Status.tsx`를 각각 기존 위치에 덮어씁니다.
4. 새 파일 `GameUI.tsx`는 위 TSX 파일들과 같은 디렉터리에 추가합니다. 상대 경로 `./GameUI`로 참조합니다.
5. 기존 개발 서버를 실행해 확인합니다. 새 npm 패키지나 이미지 파일은 필요하지 않습니다.

## 테마 수정

`globals.css` 상단 `:root`가 전역 디자인 설정입니다. 컴포넌트에서 색상 HEX 값을 직접 사용하지 않습니다.

- `--paper`: 게임의 기본 페이지색
- `--paper-soft`: 바깥 배경, 보조 영역
- `--ink`: 기본 글자색
- `--green`: 기본 강조색과 긍정/관계 색
- `--red`, `--blue`, `--ochre`, `--violet`: 건강/정보/재화/특별 사건 계열
- `--accent`: 주요 버튼과 선택 상태 (다른 색 계열을 지정할 수 있음)
- `--font-story`, `--font-ui`: 이야기와 UI의 글꼴
- `--story-size`, `--story-leading`: 이야기 글자 크기와 줄간격
- `--radius`, `--screen-width`, `--page-padding`, `--control-height`: 기본 UI 규격

예: `--paper: #ffffff;`로 바꾸면 일지, 화면 상하단 등의 기본 배경이 흰색으로 바뀝니다. `--accent: var(--blue);`로 바꾸면 주요 버튼과 선택 표시가 파란 계열로 바뀌며, 능력치의 역할별 색은 유지됩니다. 글꼴은 시스템에 설치된 것을 우선 사용하며, 별도 웹폰트 설치/다운로드는 하지 않았습니다.

## 바뀐 화면

- HUD: 날짜, 회사 이름, 건강/스트레스/회사 자금/동료 아이콘과 숫자
- 시작: 책처럼 배치된 기존 프롤로그, 밑줄 입력란, 3개 직군 선택 타일
- 일지: 최신 날짜의 연속 기록을 먼저 보여 주고, 이전 기록은 접었다 펼칠 수 있게 변경. 저장 및 내보내기에는 모든 기록이 남습니다. 진행 후 최신 기록으로 스크롤합니다.
- 일정: 기존 낮/밤 행동 선택 규칙과 잠금 조건을 유지하면서, 드롭다운을 타일 선택창으로 변경. 알려지지 않은 행동 ID는 기본 아이콘을 사용합니다.
- 상태: 역할별 아이콘, 능력치 바와 재화 정보, 기존 경영 버튼 유지
- 신화 사건: 기존 카드 이미지 및 선택지는 그대로 사용하고 특별한 사건에만 별도 색조 적용

## 확인 범위

첨부된 UI 파일만 수정했습니다. 기존 `@/lib` import와 게임 규칙 함수, 저장 포맷, 이벤트 ID, 콜백 인자는 그대로 유지하도록 작성했습니다. TypeScript/TSX 단일 파일 변환 및 CSS 파싱, CSS 변수 참조 확인은 통과했습니다. 전체 프로젝트의 `lib` 파일, package.json, 실제 이미지 자산 등이 제공되지 않았으므로 실제 Next.js 빌드, 전체 타입 검사 및 플레이 테스트는 하지 못했습니다. 기존 프로젝트에서 특히 일정 행동 선택, 이벤트 선택, 다음 주/월 이동, 저장 및 불러오기를 확인해 주세요.
